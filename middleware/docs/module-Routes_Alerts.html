Type Definitions

AlertData

The AlertData object represents the alerts being shown on the User View as invoked by the admin through the Admin View. This object is created during the callback of the alert route as it is set in Firebase.
Type:
  • Object
Properties:
Name Type Attributes Default Description
message string The main content of the broadcast alert.
type string <optional>
 'info' The severity/category of the alert (e.g., 'info', 'warning', 'urgent').
active boolean Whether the alert is currently visible to users.
timestamp Object Server-side timestamp of when the alert was created.
createdBy string Email of the administrator who posted the alert.
