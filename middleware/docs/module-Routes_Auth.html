Methods

(async, inner) POST /api/auth/verify(req) → {Promise.<UserVerificationResponse>|Promise.<Object>|Promise.<Object>|Promise.<Object>}

The verification process of a given user utilizes a three-step approach. The system checks whether the given user is found in the facilitator/organizer database. If not, it then checks the event roster in Firebase. Lastly, the user (if found) is written to the database of valid users. Otherwise, an verification error is thrown back to the system.
